## ✨ Что такое Crystall?

Crystall создавался для моментов, когда переключение на вкладку браузера стоит вам **всей комнаты**: собеседования, продающие звонки, стендапы, лекции, живой дебаг. Он парит поверх рабочего стола в тонком полупрозрачном оверлее, оставаясь **невидимым для записи экрана и трансляций** — и никакой бот никогда не присоединится к вашему звонку.

|         🪶 Лёгкий         |           🕶️ Невидимый           |            ⚡ Мгновенный            |
| :-----------------------: | :-------------------------------: | :---------------------------------: |
|  **9–16 МБ** установщик | Не отображается в записях экрана | Запуск быстрее **100 мс** |
| Доля размера Electron-аналогов | Без ботов в звонках и участников | Глобальные хоткеи из любого окна |
| Минимум CPU и RAM даже вживую | Прячется из Dock и панели задач | Стриминговые ответы, живая транскрипция |
| Сделан на **Tauri 2** (ядро Rust) | | |

## 👋 Знакомство с оверлеем

Crystall живёт в одном плавающем окне с двумя переключаемыми режимами. Оно над всеми приложениями, но не мешает работать: передвигается удержанием `Ctrl`/`Cmd` и стрелок, вызывается хоткеем из любой программы и появляется только тогда, когда нужно вам.

---

## 💬 Режим Ask — спросить обо всём на экране

Наберите вопрос, продиктуйте его голосом (push-to-talk) или дайте Crystall **увидеть ваш экран**:

- 📸 **Скриншот** — захват всего экрана или перетаскиванием выделенной области;
- 📎 **Файлы** — прикрепите документ; встроенный **OCR** распознает текст и сохраняет его в контексте для уточняющих вопросов;
- 🖼️ **Use image** — каждый следующий вопрос автоматически несёт свежий снимок экрана.

Ответы стримятся как **Markdown**, а вся история сохраняется локально — её можно искать, экспортировать или удалить.

---

## 🎧 Режим Listen — слышать разговор и успевать с ответом

Нажмите Start — и Crystall **в реальном времени** транскрибирует ваш микрофон и системный звук, с разделением по спикерам и выбором языка.

Автоматические ответы срабатывают **когда кто-то задаёт вопрос**, **после каждой паузы** или **только по нажатию Suggest**. Под каждым ответом появляются умные чипы-продолжения, сгенерированные из реального разговора. Каждая сессия сохраняется как встреча с полной расшифровкой.

## 🧭 Рабочий стол

| Раздел | Что умеет |
| --- | --- |
| **Chats** | Все сессии Ask и встречи Listen — история, поиск, экспорт, удаление |
| **System prompts** | Готовые персоны-промпты для любой ситуации, свои шаблоны |
| **Responses** | Тонкая настройка длины ответа, языка и автопрокрутки |
| **Screenshot** | Захват области или всего экрана для вопросов «что здесь?» |
| **Audio** | Выбор устройства ввода, переключение захвата системного звука |
| **Cursor & Shortcuts** | Переназначение всех глобальных хоткеев, стиль курсора |
| **App Settings** | Тема, прозрачность, поверх всех окон, автозапуск, видимость иконки |
| **Dev Space** | Свои ИИ и распознавание речи — без привязки к серверу |

### 🔌 Dev Space — свои модели без ограничений

Crystall **не** продаёт подписку и не гонит трафик через чужой сервер. В **Dev Space** вы подключаете любую модель обычным `curl` — **OpenAI, Claude, Grok, Gemini, Mistral, DeepSeek** или собственный endpoint:

- любой API в стиле chat-completions (включая картинки);
- любой сервис распознавания речи (STT);
- ключи и настройки хранятся **только на вашей машине** и передаются провайдеру напрямую.

## 🚀 Установка

Скачайте нужный файл с **[Releases](https://github.com/htmfff/Crystall/releases)** и запустите установщик.

| Платформа | Файл | Примечание |
| --- | --- | --- |
| Windows (x64) | `Crystall_*_x64-setup.exe` или `.msi` | Обычная установка, ярлык в меню «Пуск» |
| macOS (Apple Silicon) | `Crystall_*_aarch64.dmg` | После запуска — `right-click → Open` или `xattr -d com.apple.quarantine /Applications/Crystall.app` |
| Linux (x64) | `.AppImage` / `.deb` | Требуются системные библиотеки WebKitGTK |

> Приложение на этапе активной разработки и пока не подписано: Windows и macOS могут показать предупреждение безопасности при первом запуске.
